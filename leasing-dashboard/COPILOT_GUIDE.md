# Microsoft 365 Copilot でダッシュボードを編集する手順

Microsoft 365 Copilot（職場用・法人版）だけで、このダッシュボードを変更するための手順です。Copilot が守るべきルールは `AGENTS.md`（同じ内容の `copilot/knowledge_AGENTS.txt`）にまとめています。

Copilot はファイルを直接書き換えたり、テストを実行したりはできません。そのため、次の流れで進めます。

1. Copilot に変更内容を指示する
2. 回答のコードを、自分でファイルに貼り付けて保存する
3. `selftest.html` で動作を確認する

Node.js は不要です。

SharePoint で共有する方法（Excel レポート・ページ・Copilot への質問）は `SHAREPOINT_GUIDE.md` を参照してください。

## 準備（最初の 1 回）

1. このフォルダ（`leasing-dashboard`）を OneDrive または SharePoint に置き、PC に同期します。
2. 編集用のエージェントを作ります（おすすめ。毎回ルールを説明しなくて済みます）。
   1. Microsoft 365 Copilot で「エージェントを作成」を開きます。
   2. 「構成」タブの「指示」に、`copilot/agent_instructions.txt` の内容をすべて貼り付けます（8,000 文字以内に収めています）。
   3. 「知識」に `copilot/knowledge_AGENTS.txt` を追加します（エージェントの知識に `.md` を追加できない場合があるため、`.txt` 版を用意しています）。
   4. 名前を「リーシングダッシュボード編集」などにして作成します。

エージェントを作らない場合は、Copilot Chat で毎回 `AGENTS.md` を添付してください。Copilot Chat には `.js`・`.html`・`.css`・`.md`・`.txt` を添付できます。

## 変更の手順（毎回）

1. 編集用エージェント（または Copilot Chat）を開き、変更したいファイルを添付します。どのファイルかわからない場合は、添付せずに「どのファイルを添付すればよいですか」と聞いてください。
2. 下の例のように指示します。
3. 回答のコードを、指示された範囲に貼り付けます。
   - メモ帳の場合は「名前を付けて保存」で文字コードを UTF-8 にします。
   - 置き換える範囲（最初と最後の行）が回答に示されるので、その範囲を丸ごと置き換えます。
4. `selftest.html` をダブルクリックして、Edge または Chrome で開きます。「すべて OK」になることを確認します。
5. `index.html` を開き、変更した画面を確認します。
6. NG が出た場合は、NG の行をそのまま Copilot に貼り付けて「修正してください」と指示します。

変更前のファイルは、念のためコピーを取っておくと安全です（OneDrive / SharePoint の「バージョン履歴」からも戻せます）。

## 指示文の例

```
長期空室とみなす日数を 90 日から 60 日に変えてください。
（添付: config.js）
```

```
物件一覧に「申込戸数」の列を追加してください。表示は他の戸数の列と同じ書式で、null は「データなし」と表示してください。
（添付: app.js）
```

```
物件マスターの「AM担当」列（イニシャルで管理）でも絞り込めるようにしてください。
（添付: config.js）
```

```
週報の様式 A で、見出しが「募集賃料」ではなく「現募集賃料」と書かれていても読めるようにしてください。
（添付: ingest.js）
```

```
selftest.html で次の NG が出ました。原因と修正を教えてください。
（NG の行を貼り付け。添付: 関係するファイル）
```

## うまくいかないとき

- **回答のコードが途中で切れる:** `app.js`・`core.js` は長いため、「変更する関数だけを出力して」と指示してください。
- **どこに貼ればよいかわからない:** 「置き換える範囲の最初と最後の行を示して」と指示してください。
- **自己診断が開けない、または白い画面になる:** ファイルの文字コードが UTF-8 か確認し、変更前のコピーに戻してからやり直してください。
- **新しい週報の様式に対応させたい:** 確認用の架空データ（Excel）の作成に Python と Node.js が必要です。様式の見本（数値・氏名を伏せたもの）を添えて、開発者に依頼してください。
